# 八幡地区 iPadで進めるClaude Code操作マニュアル

作成日：2026年10月4日

**この手順は、iPadのSafariでClaude Codeのクラウド版を使うためのものです。** PCのフォルダ選択は使いません。洋平さんが操作する順番、押すボタン、入力する文字、送る文章を以下に示します。四角い枠の文章は、枠内を全部コピーして送ってください。

目的は、上田さんの元帳を基盤に、前日確定・当日変更・取消し・供給できる船を把握し、3隻と4隻の対応の差を検証することです。まず入力用Excelを試作し、動作を確かめてから年度全体へ広げます。

必要なものは、iPad、Safari、Claude Codeを使えるClaudeの契約、GitHubアカウントです。公式資料ではPro・Max・Team、対象席を持つEnterpriseが利用対象です。GitHubは今回の元資料と成果物の保管場所として使います。本書は個人アカウントで開始する操作を基本とします。会社のTeam・Enterpriseを使う場合は、管理者がGitHub接続を有効にしている必要があります。[公式：Claude Codeの開始手順](https://code.claude.com/docs/ja/web-quickstart)

本書は公式の操作説明を確認して作成しています。洋平さんのiPad画面と契約状態は現在のデータでは確認できません。画面の言語・アカウントによってボタン表記が異なる場合は、併記した日本語／英語を照合してください。iPadで一連の操作やExcelの動作を実機確認したという意味ではありません。

1. このチャットの「八幡4隻検証_資料一式.zip」を開きます。
2. 共有メニューから「ファイルに保存」を選び、iPadで保存できる場所へ保存します。
3. 「ファイル」アプリを開き、「八幡4隻検証_資料一式.zip」があることを確認します。
4. ZIPはそのまま使います。iPad上で中身を解凍して、一つずつ添付する必要はありません。

ZIPには上田提出の4点、関門の要目表、2026年9月の予定表PDF3点、失敗版Excel2点、具体的な作成条件が入っています。元資料の内容は変更していません。2025年度の前日最終予定表は含まれていません。これは上田さんの照合作業で補う情報です。

## 2　GitHubに保管場所を作る

GitHubアカウントがある場合は、そのアカウントでサインインして2-2へ進みます。

### 2-1　アカウントがない場合

1. Safariで[https://github.com/signup](https://github.com/signup)を開きます。
2. メールアドレス、パスワード、ユーザー名を、ご自身のアカウントとして入力します。これらは本書の文字を貼り付ける欄ではありません。
3. 画面の案内に従って登録し、届いたメールでアドレスを確認します。

登録画面は利用する認証方法で変わります。会社で用意済みのアカウントがある場合は、その登録情報を使います。[公式：GitHubアカウント作成](https://docs.github.com/ja/account-and-profile/how-tos/account-management/creating-an-account-on-github)

### 2-2　今回の保管場所を作る

1. Safariで[https://github.com/new](https://github.com/new)を開きます。
2. 次のとおり入力・選択します。

| 画面の欄 | 入力・選択する内容 |
|---|---|
| Owner（所有者） | 今サインインしている、ご自身のアカウント |
| Repository name（名前） | `yahata-tug-4` |
| Description（説明） | `八幡地区の常駐4隻体制検証` |
| Visibility（公開範囲） | **Private（非公開）** |
| READMEを追加する項目 | **オン** |
| .gitignore | 未選択のまま |
| License | 未選択のまま |

3. **Create repository（作成）**を押します。
4. 画面上部に「yahata-tug-4」と「Private」が出ていることを確認します。

すでに同名の保管場所がある場合はそれを使い、元資料があるかを確認します。公開範囲を非公開に設定してから資料を置きます。[公式：保管場所の作成](https://docs.github.com/ja/repositories/creating-and-managing-repositories/creating-a-new-repository)

**次へ進める状態：「yahata-tug-4」の非公開ページが開いている。**

[公式：ファイルの追加](https://docs.github.com/ja/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

## 4　Claude Codeを開き、この保管場所へ接続する

1. Safariの別のタブで[https://claude.ai/code](https://claude.ai/code)を開きます。
2. Claudeのアカウントでサインインします。
3. GitHub接続を求められたら、**Sign in with GitHub／GitHubでサインイン**を押します。
4. 手順2と同じGitHubアカウントで接続し、Anthropic／Claudeの連携であることを確認して認可します。
5. 非公開の保管場所へアクセスするため、**Claude GitHub Appのインストール**へ進みます。案内が出ない場合は[公式のインストールページ](https://github.com/apps/claude/installations/new)を開きます。
6. 設置先はご自身のGitHubアカウントを選びます。
7. **Only select repositories（選択した保管場所のみ）**を選び、**yahata-tug-4**を指定します。
8. 表示された権限を確認し、**Install（インストール）**を押します。
9. Claude Codeのページへ戻ります。環境作成が表示された場合は、公式案内どおり初期値のまま**Create & finish**で作成します。すでにDefaultがある場合は作成不要です。
10. 入力欄の下の保管場所選択で、**yahata-tug-4**を選びます。最初のブランチは既定のものを選びます。
11. モード選択は**Accept edits（編集を受け入れる）**にします。手順5では資料展開と条件の保存、手順6以降ではExcelを作成します。

今回はPlanを経由しません。解析とExcel作成は、以下の送信内容で段階を分けます。実行確認が出た場合は、資料の読取・展開、作成、検証に必要な処理かを確認して対応してください。

[公式：Claude Codeの接続・開始](https://code.claude.com/docs/ja/web-quickstart)／[公式：GitHub Appのインストール](https://docs.github.com/en/apps/using-github-apps/installing-a-github-app-from-a-third-party)

## 5　最初に送る文章――元帳の確認

次の枠内を全部コピーし、Claude Codeの入力欄へ貼り付けて送信します。

```text

02_予定表_2026参考のPDF3点は、版の違いを確かめる参考です。2025年度の元帳へ結び付けないでください。03_失敗版参考のExcel2点は、失敗の確認用です。入力用Excelの設計や項目名を流用しないでください。

まだ新しいExcelは作らず、画面上に次の4点を報告してください。
1. 読めたファイル名と、読めなかったファイル名。
```

2025年度の前日予定表が不足していても、試作には進めます。実績時刻の意味が分からない部分は候補・確認待ちとして扱います。確認の質問が返ったものの、今は答えられない場合は次を送ります。

## 7　同じ会話へ送る文章――7項目の動作検証

```text

試験用の架空データは試験専用コピーに入れ、元の実績や納品用の実集計へ混ぜないでください。各試験の入力値、期待値、実際の結果、合否、修正内容を「試作確認結果_v01.md」に書いてください。

1. 同時稼働：A船9:00～10:00、B船9:00～10:00、C船9:30～10:30を、別の本船作業に入力する。9:30～10:00の最大同時稼働は3隻。同じA船の同一記録を重複登録しても4隻にしない。同じ船へ同時刻の別作業を割り当てた場合は重複配船として警告する。
```

## 9　入力者として試す

Excelで開ける環境で、次の5点を確認します。iPad版Excelでの確認と、上田さんのPC版Excelでの確認は区別して記録します。

| 操作 | 確認する結果 |
|---|---|
| 開いた直後を見る | 最初に押すシートと入力する場所が分かる |
| 前日確定を1作業入力 | 本船名・実績時刻を打ち直さず、予定タグと時刻を選択・入力できる |
| 同じ作業に変更を2回入力 | 前日確定と2回の変更が残る |
| 試験用コピーのマスターへ船を1隻追加 | 追加船がタグ選択に現れ、会社・基地港も表示される |
| 試験用コピーで取消しを1件入力 | 実績がない作業でも記録でき、集計へ反映される |

これを試せるExcel環境がない場合は、上田さんのPCで確認します。iPadで資料が表示できただけで「Excelの動作確認済み」としません。

不具合があれば同じClaude Codeの会話へ、次の書式で具体的な結果を送ります。角括弧の中だけ実際の内容へ置き換えます。
